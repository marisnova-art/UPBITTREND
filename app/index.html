업비트 실제 거래 가져오기

업비트는 웹페이지에서 바로 오는 개인 API 요청을 막아요. 그래서 PC 도우미가 업비트에서 거래내역을 받아 파일로 저장하고, 그 파일을 여기에 올리는 방식이에요. 키와 기록은 PC 밖으로 나가지 않아요.

  1. 키 만들기 · 업비트 > 마이페이지 > Open API 관리에서 자산조회·주문조회만 켜요(주문하기·출금은 끄기). 허용 IP에는 도우미를 돌릴 PC의 IP를 넣어요.
  2. 도우미 받기 · quantera-upbit.bat (Windows) 을 받아 더블클릭해요. 처음 한 번 키를 넣고, 며칠치를 가져올지 정해요. "Windows의 PC 보호" 창이 뜨면 추가 정보 > 실행을 눌러요.
  3. 파일 올리기 · 만들어진 quantera-upbit-날짜.json 을 아래에서 골라요. 이미 가져온 주문은 다시 넣지 않아요.

로그인

업비트트랜드와 같은 계정이에요. 로그인하면 관심 종목·거래일지·화면 배치가 기기 간에 맞춰져요.
