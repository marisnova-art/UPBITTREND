업비트 실제 거래 가져오기

업비트는 웹페이지에서 바로 오는 개인 API 요청을 막아요. 그래서 PC 도우미(Windows 프로그램)가 업비트에서 체결 내역을 받아 올려요. 업비트 키는 PC 밖으로 나가지 않아요.

  1. 키 만들기 · 업비트 > 마이페이지 > Open API 관리에서 자산조회·주문조회만 켜요(주문하기·출금은 끄기). 허용 IP에는 도우미를 돌릴 PC의 IP를 넣어요.
  2. 연결 코드 만들기 · 에서 "코드 만들기"를 눌러요(자동 복사).
  3. 도우미 받기 · quantera-upbit.bat 을 받아 더블클릭해요. 처음 한 번 업비트 키와 연결 코드를 넣고, 자동 실행을 켜면 1시간마다 + PC를 켤 때 알아서 올려요. "Windows의 PC 보호" 창이 뜨면 추가 정보 > 실행.

직접 올리기: 도우미에서 2번(파일로 저장)을 고르면 quantera-upbit-날짜.json 이 생겨요. 아래에서 골라 올리면 돼요. 어느 쪽이든 같은 주문은 다시 넣지 않아요.
